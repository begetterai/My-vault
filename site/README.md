# Сайт Ромашки — начало

Новая система, которая делается **рядом** с работающей. В `ops-system/`
ничего не меняется, кроме починки поломок: смена работает там весь период
разработки. План — [[1-Области/Ромашка/Сайт-дорожная-карта]].

Здесь пока то, что можно сделать без сервера. Домен и сервер ждём от Азиза;
когда появятся, этап «фундамент» сведётся к выкладке готового.

## Что уже есть

| Файл | Что это |
|---|---|
| `db/schema.sql` | Схема PostgreSQL, 16 таблиц. Разворачивается без ошибок |
| `db/import_checklists.py` | Перенос листов из JSON работающей системы, со сверкой |
| `app/storage.py` | Слой доступа с **теми же именами функций**, что в `ops-system/app/storage.py` |
| `tests/test_storage.py` | 25 проверок на живой базе, без сети |

## Два решения, которые здесь заложены

**Человек опознаётся числом, а не именем.** В таблице ключом было имя,
и два тёзки означали общую явку, общие баллы и взаимное закрытие отрезков.
`chat_id` стал обычным полем, которого может не быть, — сотрудника без
телеграма теперь можно завести.

**Имена функций хранилища совпадают со старыми.** `team()`,
`filled_today()`, `segments()`, `take_station()`, `start_day()` и
остальные. Механику — сроки, баллы, правила смены — мы переносим из
работающей системы почти без правок, и она обращается к хранилищу вот
этими именами. Это и превращает переписывание в перенос.

## Что проверяют тесты

Не «выполняется ли запрос», а то, из-за чего система ломалась в жизни:
двойная отметка прихода, двое на одном рабочем месте, тёзки, фото
без файла, адресация листов по ролям, идемпотентность служебного журнала.

## Как запустить

```bash
service postgresql start
su postgres -c "createdb romashka_test"
su postgres -c "psql -d romashka_test -f site/db/schema.sql"
python3 site/db/import_checklists.py     # 77 листов, 1143 пункта
python3 site/tests/test_storage.py       # 25 проверок
```

## Чего ещё нет

Каркас FastAPI, маршруты, интерфейс, перенос механики (сроки, баллы,
обучение, правила смены), уведомления, экраны руководителя. Всё это —
этапы 1–7 дорожной карты, и часть из них начинается только после того,
как появится сервер.
