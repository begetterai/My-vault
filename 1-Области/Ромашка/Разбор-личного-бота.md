# Разбор личного бота

19.08.2026 · как устроен, что работает, что мешает, как с ним говорить

Бот `@Rabotyaga7_bot`, сервис Railway «Личный бот» (`independent-mercy`).
Код — `scripts/romashka_agent.py`, 995 строк.

---

## 1. Как он устроен

Три слоя, и это его главная особенность.

```
Сообщение
   │
   ├─ Слой 1. Быстрый ввод — разбор БЕЗ модели
   │     «Продукты 120 вода» → категория, сумма, дата, комментарий
   │     Работает всегда, даже если модель недоступна.
   │
   ├─ Слой 2. Модель с инструментами (Groq)
   │     Всё, что не разобрал первый слой.
   │     16 инструментов: выручка, Poster, задачи, календарь, почта.
   │
   └─ Слой 3. Подтверждение
         Всё, что ПИШЕТ или ОТПРАВЛЯЕТ, откладывается и ждёт «да».
         Чтение выполняется сразу.
```

**Почему первый слой важнее второго.** Ввод расходов — самая частая операция
и самая чувствительная к ошибке. Если бы он шёл через модель, каждая запись
зависела бы от того, правильно ли модель поняла фразу. Разбор без модели
даёт предсказуемость: одинаковая фраза всегда даёт одинаковую запись.

Это же спасло данные, когда Groq снял модель: два дня свободные сообщения
падали с ошибкой, а расходы через быстрый ввод писались нормально.

## 2. Что он умеет

| Группа | Инструменты |
|---|---|
| Деньги | запись расхода/дохода, кредиты, категории расходов из Poster |
| Выручка | за период, по каналам (в заведении / навынос / доставка), по месяцам |
| Задачи | создать, показать список — через Notion |
| Нарушения | записать, показать за период |
| Люди | контакты собираются сами, можно писать сотруднику от имени бота |
| Группы | бот в группе собирает сообщения и фото смены в журнал |
| Файлы | документ, таблица, PDF → Drive + короткий разбор содержимого |
| Голос | расшифровка через Whisper, с подсказкой из терминов Ромашки |
| Календарь | посмотреть события, создать |
| Почта | отправить письмо через рабочий Google |

Шестнадцать инструментов. Восемь из них пишут — все под подтверждение.

## 3. Что сделано хорошо

**Подтверждение перед записью.** Ни одна запись не уходит без «да».
Ошибочная трата не попадёт в бюджет молча.

**Новое сообщение отменяет ожидание.** Написал сумму, не подтвердил, написал
следующую — первая отменяется с явным предупреждением, а не записывается
втихую.

**Комментарий к трате обязателен.** Без описания бот переспросит. Через месяц
«120» без пояснения — мусор в отчёте.

**Пачка операций за раз.** Несколько строк — несколько записей, одно
подтверждение. Заносить неделю расходов задним числом можно за минуту.

**Нераспознанные строки не теряются.** В пачке бот отдельно показывает,
что не понял, и это не записывается.

**Подсказка для расшифровки голоса.** Whisper знает слова «Ромашка», «ЗБ»,
«ОВИР», «Лохути», имена управляющих — иначе он их коверкал.

**Всё пишется в журнал аудита.** Лист «Аудит_агента»: время, тип, что
пришло, что ответил. Именно по нему нашлась ошибка с моделью.

## 4. Что мешает

**Состояние живёт в памяти.** Ожидание «да/нет» хранится в переменной.
Перезапуск сервиса — ожидание пропадает, надо вводить заново. Сервис
пересобирается на каждый push в репозиторий, так что это случается часто.

**Один пользователь.** Ожидание хранится под одним ключом. Второму человеку
бот отвечает «Это бот Азиза» — по замыслу, но расширять нельзя.

**Модель — единственная точка отказа для всего, кроме расходов.** Сняли
модель у Groq — два дня «Сбой мозга» на каждый вопрос. Запасного пути нет.

**Категории задаются списком синонимов.** Каждое новое слово нужно добавлять
руками. Не попал в список — уходит в «Прочее» с пометкой.

**Модель видит только последнее сообщение.** История не передаётся: на
«а за прошлый месяц?» бот не поймёт, о чём речь.

**Нет отмены записанного.** Подтвердил ошибочно — правится только руками
в таблице.

## 5. Как с ним говорить

### Расходы и доходы

Формат: **`Категория Сумма [Дата] [Комментарий]`**

```
Продукты 120
Курение 20 18.08.2026 стики
Подписки 46.35 18.08.2026 railway
```

Работает и наоборот — **`250 помощь брату`**.

Пачкой — каждая операция своей строкой, подтверждение одно на все:

```
Продукты 120 вода
Массаж 300
46,35 сервер railway
```

**Дата:** `18.08.2026`, `18.08.26`, `18.08`, `2026-08-18`. Без даты — сегодня.
**Валюта:** `см`, `сом`, `с` — можно писать, отбрасывается.
**Категорию не узнал** — запишет в «Прочее» и пометит ⚠️, чтобы видел.

### Вопросы и всё остальное

Обычной фразой — этим занимается модель:

```
выручка за неделю
сколько потратили на аренду в июне
добавь задачу проверить инкассацию на ОВИР
напиши Владимиру что завтра поставка в 9
покажи события на завтра
```

### Голос, файлы, фото

Голосовое — расшифрует и выполнит. Документ или таблица — положит на Drive
и даст короткий разбор. Фото — сохранит; разбор фото и чтение чеков требуют
ключа Claude, он не подключён.
