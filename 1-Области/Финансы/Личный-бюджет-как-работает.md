# Личный бюджет — как всё работает

Инструкция по системе личных финансов: структура таблицы, типы операций, команды бота, что делаешь руками.

---

## Где живёт

Google-таблица **«Личный бюджет»** (6 листов) + бот в Telegram. Бот пишет операции → таблица считает всё сама. Скрипт сборки — `scripts/build_budget_pnl.py`, рассрочки — `scripts/build_rassrochki.py`.

Стиль везде: Times New Roman 13, без цветовой заливки — только рамки, жирный, выравнивание.

---

## Листы

| Лист | Что это | Трогаешь руками? |
|---|---|---|
| **Operations** | Журнал всех операций: Дата · Тип · Категория · Сумма · Комментарий. Сортируется по дате. Дропдауны на Тип/Категорию. | Пишет бот; можно и вручную |
| **PnL** | Главная таблица по месяцам (Янв…Дек + Год): доходы → расходы (блоки) → сбережения и долг → остаток. | Нет — только формулы |
| **Дашборд** | Сводка: итоги месяца, план/факт, подушка, динамика. Селектор месяца в ячейке B2. | Только «План/мес» и цель подушки |
| **Счета** | Фактические балансы (наличные/карта/сбережения) + сверка с таблицей. | Да — вписываешь балансы |
| **Loans** | Кредиты (Эсхата): журнал + текущий долг. | Журнал; погашения тянутся из Operations |
| **Рассрочки** | BNPL Alif «Салом»: остаток, ежемес. платёж, осталось + общий долг. | Да — уменьшаешь по мере оплаты |

**Правило:** сырьё — только в Operations. Всё остальное (PnL, дашборд, доли, нормы, долги, переходящий остаток) считается формулами. Руками правишь лишь то, что помечено выше.

## Четыре типа операций

| Тип | Категории | Смысл |
|---|---|---|
| **Доход** | Зарплата · Прочий доход · Кредит | Деньги пришли |
| **Расход** | 20 категорий (см. ниже) | Потребление — ушло на жизнь |
| **Накопление** | Накопления / Подушка · Инвестиции | Не трата — переложил себе |
| **Погашение** | Оплата кредита | Не трата — уменьшил долг |

**Главные строки PnL:**
- **Остаток (кэш)** = поступления − расходы − отложено/погашено. Переходит на следующий месяц. Это то, что реально на руках.
- **Чистый результат без кредитов** = заработок − расходы − отложено. Минус = живёшь на заёмные.

### Категории расходов (блоки по смыслу)
- **Обязательное / Быт:** Дом · Машина · Подписки · Рассрочка · Семья
- **Еда:** Продукты · Кафе
- **Здоровье / Тело:** Лечение / Медикаменты · Спортивное питание · Абонемент в зал · БАДы · Массаж / Сауна
- **Хотелки / Досуг:** Одежда/Обувь · Гаджеты · Подарки · Развлечение · Путешествие · Обучение · Курение
- **Прочее:** Прочее

Определения: **Семья** — регулярная помощь родным (разовый подарок → Подарки). **Продукты** — еда домой. **Кафе** — еда вне дома. **Развлечение** — досуг без еды.

## Команды бота

Бот понимает **обычную речь**, не команды. Пишешь в Telegram как есть — он сам определяет тип и категорию, показывает результат и ждёт **«да»** для записи. Всегда просит краткий комментарий (что за операция).

**Расходы:**
- «продукты 50» · «кофе 30 в кафе» · «бензин 200»
- «купил футболку 80» → Одежда
- «оплатил спотифай 50» → Подписки
- Несколько трат в одном сообщении — проведёт каждую отдельно.

**Доходы:**
- «зарплата 5000» → Доход · Зарплата
- «получил 300 возврат» → Прочий доход

**Накопления:**
- «отложил 500 в подушку» → Накопление · Подушка
- «инвестировал 300 в крипту» → Накопление · Инвестиции

**Кредиты и рассрочки:**
- «взял кредит 10000 эсхата» → Доход · Кредит + запись в Loans
- «погасил кредит 500» → Погашение · Оплата кредита (долг в Loans ↓)
- «оплатил рассрочку 59 гарри поттер» → Расход · Рассрочка

**Задним числом:** «вчера такси 20» · «2 августа продукты 40».

---

## Что делаешь руками

- **Счета:** вписываешь фактические балансы (наличные/карта/сбережения). Строка «Расхождение» показывает, всё ли учтено — своди к 0.
- **Дашборд → План/мес:** ставишь бюджет по категориям. Если факт превысил — в «Статусе» загорается ⚠ перерасход.
- **Дашборд → месяц:** ячейка B2 (1–12) — переключаешь, весь дашборд пересчитывается.
- **Подушка:** ставишь цель (сколько месяцев расходов) → видишь прогресс и сколько осталось.
- **Рассрочки:** по мере оплаты уменьшаешь «Осталось платежей» и «Остаток долга» — итоги и общий долг пересчитаются.

---

## Схема долгов (важно не путать)

- **Кредит Эсхата** → платишь → боту «погасил кредит …» → тип **Погашение** (не расход) → долг в Loans ↓.
- **Рассрочки Alif** → платишь → боту «оплатил рассрочку …» → тип **Расход · Рассрочка** (в расходах) + вручную уменьшаешь остаток в листе «Рассрочки».

**Общий долг** = долг по кредитам (Loans) + остаток по рассрочкам — сведён на листе «Рассрочки».
